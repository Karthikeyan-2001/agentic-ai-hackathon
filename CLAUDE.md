# Adaptive Exam Prep Tutor

Spec: `docs/superpowers/specs/2026-10-31-adaptive-exam-tutor-design.md`
Plan: `docs/superpowers/plans/2026-10-31-adaptive-exam-tutor.md`

## Main rule

The LLM interprets and the code decides. The LLM never sets a score, marks an answer or chooses a question. Never run code generated by the LLM.

## Rules

- `engine/` is pure: no LLM, database, network or system clock. Time is passed in.
- Only `agent/llm.py` talks to Ollama.
- LLM settings: `qwen3.5:9b`, `think=False`, `temperature` 0, `num_ctx` 8192, `keep_alive` -1, 30-second timeout, up to two retries.
- Questions cover Python Programming only. Other concepts show as "not assessed".
- The dashboard always shows a "Simulated class" label.
- Describe evaluation samples as written test cases, not real student data.

## Folders

| Folder | Owns |
|---|---|
| `content/` | Concept graph, misconceptions, questions, evaluation samples |
| `engine/` | Mastery, misconceptions, scheduling, Elo, graph, selection, class summary |
| `agent/` | LLM client, diagnosis, generation, solvers, lesson plan, agent loop |
| `api/` | Database tables, persistence, routes |
| `scripts/` | Seeding, pre-generation, evaluation, demo tools |
| `web/` | React app |

## Commands

```bash
.venv/Scripts/python -m pytest
.venv/Scripts/python -m pytest -m llm
.venv/Scripts/python -m uvicorn api.main:app --port 8000
npm --prefix web run dev
```
